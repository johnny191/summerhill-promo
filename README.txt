DEPOT INFORMATION DISPLAY
PROMOTIONAL VIDEO ASSETS

PROJECT:
Depot Information Display promotional video

CORE STORY:
Existing depot TVs were installed but often switched off.
Information was traditionally communicated using printed notices.
The new system turns the existing screens into live information displays.

KEY FEATURES:
- Real-time management messages
- Central Control messages
- Localised information for each depot
- Live news
- Live weather
- Multiple information pages
- 10 locations
- Reduced printing
- Reduced paper waste

CREATIVE CONCEPT:
OLD WAY → EUREKA → NEW WAY

OPENING:
Black and white
Switched-off screens
Paper noticeboards
Sombre music

EUREKA:
"Why don't we use the screens?"

AFTER:
Full colour
Live information
Modern music
Remote management
10 connected locations

KEY TAGLINE:
"The screens were already there.
Now they're working for us."
